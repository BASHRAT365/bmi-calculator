# ⚖️ BMI Calculator

A simple and responsive BMI Calculator built with HTML, CSS and JavaScript. Enter your weight and height to calculate your Body Mass Index and view the corresponding BMI category.

## 🌐 Live Demo

👉 https://bashrat365.github.io/bmi-calculator/

## ✨ Features

- Calculate BMI instantly
- Weight input in kilograms
- Height input in centimeters
- Display BMI value
- Display BMI category
- Input validation
- Responsive design
- Simple and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
